# Skill: git-safety — Active at All Times

## Pre-commit checks
Run mentally before every `git commit`:

1. `git config user.name` must not contain: Claude, Anthropic, Assistant, AI, Bot
2. `git config user.email` must not contain: anthropic.com, claude.ai
3. Staged diff must not contain:
   - "Generated by Claude"
   - "Co-authored-by: Claude" (any case)
   - "AI-assisted"
   - "claude-code"
   - "This file was generated"
4. Staged files must not include: .env, .env.*, *.key, *.pem, *.p12, *.pfx
5. No high-entropy strings matching API key patterns (sk-, AIza, AKIA, ghp_, glpat-)

## Conventional commit format (enforced by commit-msg hook)
```
<type>(<scope>): <description in imperative mood, max 72 chars>

[optional body]
[optional footer]
```
Types: feat | fix | refactor | test | docs | chore | perf | ci | style

## Forbidden commands (require explicit typed confirmation)
- git push --force / -f on any branch
- git reset --hard with uncommitted work
- git clean -fd at project root
- Any history rewrite on published branches

## On violation
Stop. Print the finding. Do not commit. State what must be fixed.
